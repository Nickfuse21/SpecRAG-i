C · The four hallucination controls

#ControlWhereWhat it prevents
1Release version pinningIngestion Blending contradictory Rel-15 and Rel-18 text into one confident claim
2Relevance gate highest leverageRetrieval If the corpus lacks the answer, no LLM call happens — nothing to invent
3Forced + validated citationsGeneration Fabricated clause references, caught by a deterministic set-membership test
4NLI groundedness + abstentionPost-generation Plausible sentences that no retrieved passage actually supports
Design thesis: hallucination is not solved by a better prompt. It is solved by removing the model's opportunity to guess. Controls 2 and 4 are gates, not suggestions — they can stop an answer from ever reaching the user.

The header is embedded and shown to the LLM. The model always knows which spec, which release, and which clause a passage came from — so it cannot attribute a fact to the wrong document.
